# Paper 1 文献材料

## 目录

- `notes_and_indexes`：文献地图、构念边界、待收集清单和链接核验记录。
- `bibliography`：迁移时的共享 BibTeX 文件。它们包含其他论文的条目，不应被误称为 Paper 1 专用 bibliography。
- `papers/collective_intelligence_homogeneity`：LLM 输出同质性、人机协作相关性与群体产出多样性。
- `papers/llm_social_simulation`：LLM agent 与社会模拟。
- `papers/opinion_dynamics_abm`：意见动力学与算法个性化。
- `papers/simulation_validation`：ABM 验证、ODD 与模拟方法边界。
- `papers/recommender_genai`：生成式模型与技术背景材料。
- `user_supplied_originals`：用户在对话中明确提供的论文原件。

公开 Git 仓库仅同步文献索引、BibTeX、核验笔记和链接。`papers` 与
`user_supplied_originals` 中的论文全文保留在本地，并由根目录 `.gitignore`
排除，以避免未经确认公开再分发第三方或用户提供的 PDF。

`NyhanEtAl2023` 与 `PerraRocha2019` 的用户上传文件和文献库文件具有相同 SHA-256。项目保留 `papers` 中的规范命名版本；重复副本不构成额外文献。

文献存在于本目录不等于其所有理论或结果已经完成逐句核验。正式引用应回到原文，并区分模型输出、人的信息暴露、人的意见更新与群体结果。
