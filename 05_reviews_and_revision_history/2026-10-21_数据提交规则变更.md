# 数据提交规则变更

2026-10-21，项目所有者明确指示：仓库内容需要包含原始数据，供合作者在另一台电脑 clone 后直接分析；规则改写为"不提交 API key 和模型服务凭据"即可。

## 变更内容

- 原规则"不提交 API key、模型服务凭据、参与者身份信息、受限数据或本地缓存"改为"不提交 API key 或任何模型服务凭据"。
- 原规则"新的人类数据不得与公开代码或可共享输出混放。先建立数据使用、伦理和匿名化说明"改为允许随仓库提交人类数据与研究数据。
- 假名化账户资料（01_Agent基础信息表.csv、账户资料_305.jsonl 等）、实验配置/结果/日志（06_experiments）、各交接数据包自本次起纳入版本库。

## 风险记录（所有者已知情）

- 仓库 Hankant/ABM_INFO 在变更为 private 之前是公开的；305 个真实微博账户的假名化属性快照（性别、所在地、关注/粉丝/发博数及可回溯的源表行号）推送后任何人均可见，且公开后不可真正撤回（fork、缓存、爬虫）。
- 数据的授权使用范围、伦理审查与匿名化说明文档尚未建立，后续需要补齐。

## 保持不变

- API key 与模型服务凭据仍只走环境变量（RUMOR_LLM_API_KEY）或本机 DPAPI 加密存储，绝不进入版本库。
- 本地缓存、虚拟环境、编译产物仍按 .gitignore 常规排除。
- 嵌套独立 git 仓库（socioverse2-contest、third_party_reference/SocioVerse2）因各有自己的 .git 历史，不并入本仓库，属技术约束而非数据规则。
- 超过 GitHub 100MB 单文件上限的文件（如 study.duckdb）经 Git LFS 上传。
