# SocioVerse2 目标人群抽样与生成指令

版本：2026-10-17。用途：交给人群构建 agent。本文自包含，不要求读取原稿或旧代码，不指定本地目录。当前交付为设计方案，未生成或运行实际人群。

## 1. 任务和研究对象

为“不同圈内外条件下的政府辟谣策略与信念转变”研究构建固定的模拟用户名册。比较政府启用时间 T_G、对象 In-out、接受概率 GT 在不同 PBd 条件下的结果。

原稿研究主体是谣言源关注者与非关注者。普通用户共 582 名：圈内 82 名、圈外 500 名。谣言源和政府是额外角色，不占这 582 个名额。

**这里生成的是按原稿规模和规则设定的模拟人群，不是从全部微博用户中抽取具有统计代表性的概率样本。** 现有数据来自一个事件的公开表达者，不能证明其覆盖所有浏览者或平台总体。

本阶段完成名册、群体参数、可选画像分配、来源标签和检查。位置、有效接触、政府投送归环境模块；PB→RC、GT→RF 抽样归行为模块；结果归指标模块。

## 3. 生成模式：主流程与可选画像

### 3.1 主流程：规则型合成人群

不需要外部人群服务或逐人资料，即可生成 582 个独立模拟身份和原稿群体参数。默认不附会年龄、性别、职业、教育、政治立场或心理人格，因为这些属性没有在本次概率规则中承担已确认作用。

名册可以先完成，但初始状态和环境细节尚未落实时，不能宣称完整模拟已就绪。以 null 表示未确定值，不以 0 或空字符串混充。

### 3.2 可选：公开账号画像附加

只有收到可用的去标识画像数据且研究者选择复用时，才运行画像分配。没有该文件时，使用主流程即可，不等待用户提供无关材料，不凭空生成“真实画像”。

画像只附加公开计数字段，不影响 PB、RC、GT、RF、群体身份或接触规则。在概率基准中，加不加画像不应改变抽样轨迹；应通过隔离随机流保证这一点。

两种模式都生成同样的 582 个模拟身份。画像模式是资料展示差异，不是新的人口行为假说。

## 4. 群体参数与禁止推断

原稿表 1 的值如下，直接导入，无需再读原稿：

| scenario_id | PBd | PB_inside | PB_outside | RC_inside | RC_outside |
|---|---:|---:|---:|---:|---:|
| pbd_0 | 0 | .579 | .579 | .100 | .100 |
| pbd_02 | .2 | .679 | .479 | .117 | .083 |
| pbd_04 | .4 | .779 | .379 | .135 | .065 |

PBd=PB_inside−PB_outside；它是输入，不是第 5 轮实测相信比例之差。582 人的加权平均 PB 不要求在每个 PBd 条件下都等于 .579；两组人数不相等，不要为了强制总体均值而重算表格。

RC 是“相信后”的条件概率，不能把 RC 当作无条件转发概率。原稿 RC=P×PB 的近似比例与表格舍入存在差别。本阶段按表格建立参数草案并标记 `parameter_basis=manuscript_table_1`；后续若决定精确重算，必须形成版本变更，不静默覆盖。

同组成员使用该组概率，不加入 ±.05、正态扰动、Beta 分布或人格调节。用户的异质性来自群体规则与随机过程，不需要再编造个体概率差异。

GT 属于当前政府策略，不是每个用户独立生成的“政府信任人格”。RF=.6 是接受纠正后的传播概率；不得把它改成事先固定选出 60% 用户“愿意分享”。

## 5. 按顺序执行的生成规则

### P01：创建身份和固定配额

1. 创建稳定、无真实身份含义的标识：`A0001` 至 `A0582`。
2. 建议前 82 个身份赋 inside，其余赋 outside。这是便于审计的编号约定，不表示用户有排序、影响力或接触先后。
3. 不按标识顺序安排传播优先级。若调度按 ID 顺序有行为后果，应在环境轮内顺序中解决，不偷偷改人群抽样。
4. inside 的 follows_source=true，outside=false。普通用户总数保持 582。
5. 在单独角色表创建 `SOURCE` 与 `GOVERNMENT`，不能为其复用普通用户 ID。

圈内外成员不根据粉丝数、历史立场、未来转发或之后的模拟结果分配。跨越空间圈层不重新分组。

### P02：绑定场景概率

生成独立的场景参数表，根据 scenario_id 与 group 绑定 PB、RC。不要在切换 PBd 时重新生成身份、画像分配或群体成员。

T_G、In-out、GT 由干预配置给定，不按人随机抽取。UA=2、LC=250 等环境参数保持在环境合同中，不把它们改为新人格属性。

### P03：处理初始状态

目前已明确状态含义，但交接资料尚未提供足以确认所有普通用户初始状态及初始传播者配置的完整初始化规则。

- 名册先保留 `initial_state=null`，并记录该缺口。
- 可提出“普通用户初始 S，SOURCE 单独作为源”的候选初始化，但必须标为建议，不说成已从原稿核实。
- 不以 PB 为概率在初始化时预先抽一遍相信，再在首次接触时重复抽样。
- 不用历史评论立场设置初始 E、I 或 R。
- 初始状态未确定不阻塞身份与参数表生成，但阻塞正式推演。

### P04：可选画像抽样

接收数据最小字段：`donor_id` 和 `observed_profile`。后者只允许 `followers_count`、`following_count`、`statuses_count`。这些是账号快照，不是心理参数。

逐项检查：donor_id 唯一；计数为非负整数或缺失；缺失保留 null，不补零；缺少 donor_id 的记录不参与抽样并列入排除日志。重复 donor_id 的冲突不能默默保留第一条。

按照已核对的现有工程抽样方法：

1. 按 donor_id 排序候选库，消除输入文件行序的影响。
2. 候选数 M≥582：均匀无放回抽取 582 份。
3. 0<M<582：先均匀无放回选出全部 M 份，再从全部 M 份中均匀有放回抽取 582−M 份。
4. 将完整的 582 份抽样结果再次随机打乱，随后按固定 agent_id 顺序分配。不要把最先抽到的真实画像固定给圈内用户。
5. 若 M=305，则先选全体 305 份，再抽 277 份补足；最后共 582 份分配、305 个不同来源。不能说新增了 277 个实测用户。
6. 同一 donor 被使用多次时，每个 agent 拥有独立状态、记忆容器和行动记录；深拷贝画像，不能共享可变对象。
7. M=0 时停止画像模式并报告输入为空；可以继续无画像名册，不静默伪造资料。

每份 donor 的复用次数不必相等；不要新增“每人最多复用两次”的约束。记录实际复用次数与圈内外分配，不因抽样结果不平衡而重抽到满意为止。

这是现有工程的画像复用办法，不是总体代表性抽样或对真实社会构成的估计。

### P05：固定随机性和可比较性

使用显式配置的 population_seed、固定排序和稳定随机数算法；记录算法及版本。未给定种子时可用 1 做工程检查，但标记测试用途，不自动成为正式重复设计。

画像分配使用独立随机流，不消耗行为和空间运动的随机数。不可使用语言内置的不稳定 hash，或依赖运行名称、文件夹、T_G、In-out、GT 产生画像种子。

同一重复内比较不同政府策略时，名册、群体身份和画像分配保持完全一致。不得每个分支重新抽一群人。改变 PBd 时可以复用相同名册，但这是场景版本变化，不冒充只改变环境的政策分支。

规则等价不等于逐人 donor 分配和旧工程完全一致；若要求旧分配逐人一致，需要旧分配结果或完全相同的种子派生算法，本轮不承诺该项。

### P06：输出并验证

输出名册、角色表、参数表、画像分配表（可选）、来源与检查报告。所有文件使用接收端支持的 schema；下列字段属于本研究内部合同，不冒称上游原生字段。

| 字段 | 含义／约束 |
|---|---|
| agent_id | 唯一模拟用户标识 |
| group | inside 或 outside，固定 |
| follows_source | 与 group 一致 |
| initial_state | S/E/I/R 或尚未确定的 null |
| scenario_id | 指向场景参数表，不代替用户身份 |
| pb、rc | 按该场景及固定 group 查表 |
| donor_id | 可选，未使用画像时为 null |
| observed_profile | 可选公开计数，不进入概率计算 |
| population_origin | rule_defined_synthetic_population |
| group_origin | experimental_assignment |
| profile_origin | absent 或 observed_public_account_snapshot |
| profile_time_status | 附加已有画像时注明 not_verified_as_pre_event |

检查必须包含：恰好 582 个唯一 ID；inside=82、outside=500；特殊角色未混入；PBd 与表一致；PB、RC 在 [0,1]；同组无未经授权的概率差异；相同 seed 重现；数据行序变化不改变画像结果；相同 donor 的状态互不影响；策略分支不改变名册；去掉可选画像不改变行为概率。
