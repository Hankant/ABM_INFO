# SocioVerse2 报告与验收指令

版本：2026-10-17。用于同一谣言与政府辟谣研究。无需重新读取原稿或旧代码，不指定本地目录。

## 1. 输出原则

报告回答：在不同 PBd 条件下，T_G、In-out、GT 与模型中的相信→不相信过程有什么关系。现在尚处方案阶段，只生成报告结构和数据检查计划；取得真实完整运行产物后再填结果。

原稿的模拟规则、迁移工程验证、实际模拟结果、真实世界证据必须分别标识。Mock 页面、测试夹具或参数表不能称为研究发现。

## 2. 输入数据与检查

| 输入 | 检查 |
|---|---|
| 环境和人口 manifest | 版本、582 人配额、接触方式、规则就绪状态明确 |
| 实验配置 | T_G、In-out、GT、PBd、RF、时长、种子、重复次数明确 |
| 运行 manifest | 完整或失败标记、最后完整 tick、配置与代码摘要 |
| 每轮状态记录 | 同一时点 S/E/I/R 合计为582；群体身份固定 |
| 接触／抽样／转换记录 | 能按 contact_id、agent_id、tick 关联，无重复提交 |
| 政府事件记录 | 区分计划发布时间、实际启用及用户实际接触 |
| 验证报告 | 实际测试与 NOT_RUN 分开；不把 schema 校验视为行为正确 |

缺少必要记录时说明不能计算什么，不从图形反推或凭估计补齐。失败轨迹可以展示运行诊断，但不能无说明混入完整实验均值。

## 3. 指标口径

| 输出 | 定义与限制 |
|---|---|
| TBU | 政府开始后完成相信→不相信者的 mean(T_i−T_G)，原稿条件 T_i>T_G；未完成者排除，无完成者记缺失 |
| 完成者人数 | 与每个 TBU 同时报出，使分母可见 |
| 圈内外状态人数 | 按固定身份统计 S/E/I/R，不按当轮位置重分组 |
| 实际接触数 | 分谣言／纠正及来源角色；是接触事件数，不自动等于去重人数 |
| 去重触达人数 | 明确观察区间与内容类别；同人多次接触只算一个人 |
| 传播次数 | 谣言与纠正分别记录，不等同相信人数 |
| 转变比例 | 已讨论新增，但分母尚未确定；不得自行生成百分比 |

TBU 是完成者的等待时间，不是全体用户的平均纠正时间。它变短可能伴随较少人完成转换，因此必须同时展示完成者人数。这里仅解释原口径，不新增共同风险集、匹配或统一干预后窗口。

同轮 T_i=T_G 的真实转换保留在事件记录；不纳入要求 T_i>T_G 的 TBU。不同统计口径不得通过修改事件时间实现。

## 4. 报告结构

1. **研究和版本说明：**场景、研究范围、规则版本、哪些参数来自原稿、哪些是工程适配。
2. **设计表：**完整条件、种子和实际完成的重复数。只有单次运行时明确是单条轨迹。
3. **过程图：**各状态人数随 tick 变化，标出 T_G；圈内外可分别展示，颜色和状态含义固定。
4. **结果表：**每次运行的 TBU、完成者人数、完整性；新增比例未定时显示未定义，不填 0。
5. **接触与接受分解：**政府启用后触达多少人、其中多少接受；不把未触达者说成拒绝政府。
6. **个体轨迹：**展示接触来源、概率、随机值、前后状态和传播动作；不能挑选个体冒充整体规律。
7. **策略比较：**说明哪些因素变化、哪些保持；重复运行汇总要说明有效重复数和不确定性计算方法。
8. **差异和限制：**原稿、旧工程、新框架的改动表；未验证规则、数据与外推边界。

不预先承诺最优时机或显著性。没有足够重复时不编置信区间；逐人事件不能被当作独立的实验重复。对无完成者导致 TBU 缺失的运行，汇总时同时报告缺失数量，不静默删除。

## 5. 必须披露的数据限制

- 当前场景 event_052 的纠正文本是 scripted_no_evidence 实验脚本，不是已核验的官方纠正。
- 305 份公开账号画像若复用为 582 个模拟身份，不产生 582 名独立实测用户。
- 圈内外身份为实验设定，缺少完整实测关注网络。
- 历史公开表达是回顾性材料，不能当作事前信念或全部浏览行为。
- 模拟结果是该模型和参数下的结果，不直接证明真实政策效果；框架迁移本身不提高真实性。

## 6. 改动表和验收

每项改动列出：原稿规则、旧工程行为、新实现、是否确认、对结果的可能影响、验证证据。至少包括空间／网络接触、LLM／概率行为、GT 含义、400／80 轮、PBd 定义、TBU 窗口、画像用途、随机恢复与新增转变比例。

交付报告模板或实际报告、指标字典、改动表和验收清单。验收要求来源与计算可追溯、状态人数一致、未运行不冒充结果、未定义指标不填数字、政策比较没有隐藏的人口或规则变化。不得把“复现原稿结论”设为通过条件。
