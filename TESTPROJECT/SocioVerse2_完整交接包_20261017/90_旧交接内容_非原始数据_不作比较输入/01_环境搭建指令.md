## 1. 研究对象与边界

研究问题为：**在不同圈内外相信概率差异条件下，政府辟谣的发布时间、目标群体与政府可信度，如何影响用户从相信谣言到不相信谣言的转变？**

研究主体是单个谣言事件中的模拟用户、谣言源和政府。个体接触与状态转换发生在用户层面，策略比较在模拟群体层面进行。概念依据是原稿《Rumor Refutation in Cocooned Social Media: An Agent-Based Study of Government Capacity and Belief Updating》的方法设定，所需内容已提取到本文；不要将这些设定宣称为已由真实平台数据验证的因果机制。

| 原稿名称／符号 | 本项目含义及模型位置 | 可记录的模型量与解释边界 |
|---|---|---|
| 圈内／圈外用户 | 谣言源关注者／非关注者；固定身份 | 记录 group 与 source_following；不随位置或信念变化重新分组 |
| PB | 接触谣言后相信的概率；个体转换规则 | 记录适用概率及抽样；不等同于现实心理量表得分 |
| RC | 相信后传播的条件概率；个体传播规则 | 记录条件成立后的抽样；不能直接当作无条件传播率 |
| PBd | PB_in−PB_out；实验情境参数 | 输入值与模拟实现的群体差异分别记录 |
| T_G | 政府开始辟谣的时间；干预参数 | 记录启用时点及首次实际接触时点；二者可能不同 |
| In-out | 政府辟谣对象／活动范围；干预参数 | 记录原稿编码与实际触达对象，不改成推荐排序参数 |
| GT | 接触政府辟谣后接受的概率；干预参数 | 不作为信息流权重或提示词中的可信线索 |
| RF | 接受纠正后传播纠正的概率；行为规则 | 不作为全体用户看到纠正的概率 |
| TBU | 完成相信→不相信者的平均转变等待时间；结果 | 后续指标阶段计算；环境保存必要事件时刻 |

此区分用于分辨“尚未接触纠正”与“接触后未接受纠正”两种模型内部解释。不引入未经界定的新理论构念，不把模拟结果直接解释为现实政策效果。

TESTPROJECT 是独立项目。不要把另一个 Paper 1 项目的搜索引擎与 LLM 信息获取比较、模型路由策略等问题套入本研究。

## 3. 先冻结环境必须遵守的规则

### 3.1 接触方式的现有边界

原稿以二维空间随机移动和相遇表达接触；现有单事件代码以关注关系、活跃抽样和信息流表达接触。此前方案明确保留了这一待确认差异。本阶段应以原稿空间过程整理规格，不自动把新版信息流作为最终环境，也不宣称空间细节已全部明确。

将最终 `contact_mode` 留为未定，除非随附的后续确认已明确解决此项。优先完成空间规则对照与缺口定位；不得为了让程序运行而悄悄选择推荐信息流。只集中报告一次此项及确实无法查明的实现缺口。

### 3.2 原稿空间过程：保留什么

- 谣言源位于圈层中心。圈内用户是其关注者；圈外用户不是关注者。
- 圈内用户在圈内活动；圈外用户可以进入或离开圈内。位置跨界不改变群体身份。
- 用户随机移动，接触代表信息浏览或交换。圈外传播者离开圈层可以把信息带向外部。
- 原稿描述圈层随相信者比例扩大、在纠正后缩小。精确函数尚未明确，不自行设成线性函数。
- 政府在 T_G 开始活动，按原稿 In-out 条件开展辟谣；接触后才进入接受概率判断。
- 原稿总时长为 400 ticks，时间是抽象模拟步，不自动换算成分钟、小时或日期。

这些是待实现规则的文字依据，不是对平台真实接触过程的验证。

### 3.3 环境与行为严格分工

```text
环境：时间与位置变化 → 检测有效接触 → 给出接触记录
行为：有效谣言接触 → PB 抽样 → 相信后 RC 抽样
行为：有效政府纠正接触 → GT 抽样 → 接受后 RF 抽样
环境：应用行为结果 → 更新状态与传播资格 → 保存轨迹
```

环境不得提前抽取“相信”或“转发”，再让行为模块抽第二次。没有有效接触时不触发新的相信或接受抽样。

谣言接触的三个概率分支为 `1−PB`、`PB×(1−RC)`、`PB×RC`，前提是用户状态符合原稿适用条件。政府纠正被拒绝时保持原信念；接受后进入不相信状态，再决定是否传播纠正。

原稿 RC=P×PB 的绑定保留为原稿模型假设，不声称已有理论证明“容易相信者在已相信后必然更容易转发”。

### 3.4 禁止随框架默认行为引入的变化

- 不用 LLM 的 belief_score、60/40 阈值或自由行动替换概率模型。
- 不把一轮内给 40 人直接投放纠正当作原稿政府持续接触。
- 不新增推荐槽位、热度排序、动态取关、有限阅读、记忆增强等机制。
- 不把现有 80 轮、30 轮评估窗口、第五轮实际 PBd 当作原稿参数。
- 不默认接触所有用户，不把“政府已启用”解释为“全体已曝光”。
- 不按当前圈层位置重定义关注身份，不把政府混入 582 名普通用户计数。
- 不把完整事件日志变成影响下一轮概率的新记忆机制。
- 不规定结果必须符合原稿结论；软件验收检查规则执行，不检查政策结论方向。

### E04：设计环境层与干预入口

下列名称是本研究拟定的层名，不是上游自带研究模型：

| 层 | 标签建议：modality / scope / dynamics | 内容与可见性 |
|---|---|---|
| world_geometry | physical / macro / static | 世界几何设定；不表示真实地理地图 |
| circle_state | physical / macro / endogenous | 当前圈层几何及变化状态 |
| contact_state | physical / local / endogenous | 当前接触机会；按接收者投影 |
| government_policy | physical / macro / scheduled | 政府启用与数值策略参数；不是全员获知的公告 |

### E07：规定随机性、恢复与分支边界

环境运动随机性与行为抽样分开记录，但不能因拆分而宣称复现了未知原始随机序列。种子不得依赖目录名、run_id 或分支名字。

### E08：验证并完成交接

在接收端 Python 环境中执行结构验证。下例函数接收配置对象，不依赖任何本地目录；若导入路径与安装版本不同，先查该版本定义再调整，不通过删字段规避校验：

```python
from socioverse.schemas import EnvironmentBundle

def validate_environment(payload: dict):
    bundle = EnvironmentBundle.model_validate(payload)
    assert bundle.study_id == "rumor_refutation_migration"
    names = [layer.name for layer in bundle.layers]
    assert len(names) == len(set(names)), "Layer names must be unique"
    assert all(event.target_layer in names for event in bundle.scheduled_events)
    return bundle

# 将本阶段生成的配置字典传给 validate_environment。
# schema 校验成功不等于 provider 已实现或环境已可推演。
```

同时使用当前构建技能指定的 handoff 校验读取 study.yaml。保存实际命令、版本、返回状态与错误；没有执行的检查标记 NOT_RUN。
