# 数据使用与来源边界

本包用于本研究的本地材料准备，不自动上传平台、不调用模型、不提交版本库。源文件保持原位，不在本包复制账户昵称、主页、真实账户ID或逐条评论全文。

账户以P0001等资料编号表示，并保留源工作表和行号供研究者核查。这是可关联的假名化，不是不可逆匿名化；账户属性组合仍可能有识别风险。上传前由研究者确认原采集授权、平台使用条件和研究用途。本文不声称已经取得伦理审批或再分发授权。

人口属性、地点与数量均为账户页面快照，不视为已核实的真人属性，采集时点尚未证明早于事件。当前只生成使用这些快照的探索性草案，不作为严格事前预测的已验证输入。

本事件中的评论、转发和后加情感／赞同标签不进入初始人格或个人记忆。参与评论或转发的账户也不代表全体平台用户，尤其不代表沉默用户的随机样本。

305个资料编号与582个模拟ID之间的对应是本次新建的实验分配草案，不是原始数据中的真人身份对应。重复使用同一份资料不增加真实账户样本量。
