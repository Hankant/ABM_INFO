# 空间边界修复与验收指令

状态：供持有空间provider源码的agent执行。当前工作区未找到该实现，本文不是已经修复或测试通过的报告。无需修改研究者已确认的世界与运动参数。

## 1. 修复目标

世界为[-50,50]²，圆心(0,0)、半径20。用户步长2，政府步长1。运动必须是“走到最近边界交点，反射后继续走完剩余距离”，不能用截断、越界终点投影、原地拒绝或重抽方向代替。

圈外政府允许区域是正方形减去圆的内部。它同时受外侧四条边与内侧圆形障碍物约束。用户／政府的接触依然只在运动结束后计算，不因几何路径碰撞检测而新增中途信息接触。

## 2. 统一几何函数

两个框架共用一个纯函数，不各写一套：

```text
move_reflect(position, unit_direction, distance, region)
    -> final_position, final_direction, segments, collision_events
```

region必须区分：

| 对象 | region | 检测的障碍 |
|---|---|---|
| 圈内用户 | disk | 圆外不可进入 |
| 圈外用户 | square | 仅四条外边；可以穿过圆 |
| In-out=2政府 | disk | 圆外不可进入 |
| In-out=1政府 | square | 仅四条外边；可以穿过圆 |
| In-out=0政府 | square_minus_disk | 四条外边＋禁止进入圆内部 |

不得把圈外用户与圈外政府使用同一region。region只由角色、固定群体及政府策略确定，不随当轮信念变化。

## 3. 最近碰撞算法

1. 验证位置位于允许区域、方向为非零有限向量、距离非负；将方向归一化。
2. 将剩余路程记为L。计算射线p+s·d与所有有效边界的候选碰撞距离s。
3. 选择本段内最早的有效碰撞；没有碰撞则直接走完L。
4. 有碰撞时，先移动s到交点，保存这一段，令L=L−s。
5. 计算碰撞法向量n，按 `d_new=d−2(d·n)n` 反射。
6. 用新方向继续处理剩余L，允许同tick多次碰撞；直到剩余距离耗尽。

每次碰撞后重新计算候选，不能只允许一次反射。碰撞次数达到保护上限时显式报错，不能默默丢掉剩余路程。

### 圆形边界

令q=p−c，单位方向d，求解：

```text
s² + 2(q·d)s + (q·q−R²) = 0
```

交点h=p+s·d，单位法向量n=(h−c)/R。

- disk：只在即将离开圆内时反射。
- square_minus_disk：只在即将进入圆内部时反射。
- 障碍圆的切线擦过不进入内部，不反射。
- 不能只检查终点在圆内还是圆外：路径可能穿过圆后在另一侧离开。
- 起点位于边界且方向进入禁止区域时，执行零距离反射；反射后离开该边界的零根不得再次触发。

### 正方形边界

对当前方向可能到达的x=±50、y=±50分别计算射线距离，取最早碰撞。精确命中角点时同时翻转相应两个方向分量，不能因遍历边的顺序不同而改变结果。

## 4. 浮点约定

建议以绝对位置容差1e-10和路径长度验收容差1e-9作为本尺度下的共同工程约定，两框架一致；这是新增数值约定，不是原稿参数。

边界吸附仅用于校正容差内误差，不能把明显越界的点强行投回。若必须扰动坐标以避开零距离循环，应记录扰动量并检查累积误差，不把隐藏位移当作精确镜面运动。

内圆区域中“恰在圆边界、方向完全切向”的初始条件是退化情形：直线继续会立即出圆。不得陷入无限循环或假称无碰撞。第一版应显式检测并报出退化输入；正式随机初始化和移动若遇到它，不应静默重抽。实现者若增加统一正则化规则，需单独记录并在两框架使用相同规则。

所有方向都先归一化；以下均为解析可核对的期望值。

| 编号 | region | 起点 | 方向 | 距离 | 期望终点 | 主要检查 |

| T02 | disk | (19,0) | (1,0) | 2 | (19,0) | 碰圆后走剩余1，不能停在(20,0) |
| T03 | square_minus_disk | (20.5,0) | (-1,0) | 1 | (20.5,0) | 圈外政府撞圆后反射 |

另加一个斜向圆碰撞用例：p=(19,0)，d=(.6,.8)，L=2。碰撞距离 `s=−11.4+sqrt(168.96)`，碰撞点h=p+s·d，法向量n=h/20；期望终点为 `h+(2−s)[d−2(d·n)n]`。测试预期必须由该解析式独立计算，不能调用待测函数生成预期值。

## 6. 性质与回归检查

- 每段长度之和等于传入路程，误差在共同容差内；不能只检查起终点距离。
- 每一段都位于允许区域。对于square_minus_disk，检查圆心到线段的最小距离≥20−容差，不能只检查端点。
- 最终方向保持单位长度；碰撞满足法向分量反号、切向分量不变。
- 一次走L与沿返回方向连续走L1、L2（L1+L2=L）应一致；中间不重新抽方向。
- 同一输入跨两个框架返回同一终点、方向与碰撞序列。
- 政府T_G前位置不变；In-out=0运行后所有运动段均不进入圆内。
- 政府在圆外、用户位于圆内但距离≤2时，仍按已确认距离规则判断接触；不额外添加身份筛选或“圆边界阻挡信息”规则。
- 距离等于2时应接触；边界移动修复后重跑受影响的接触回归，不能只看几何函数测试。
