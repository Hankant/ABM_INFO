## 关于初始化数据的三个纠正

1. 上一个包中的A0001—A0582是交接时生成的编号约定；原代码实际使用C001—C082和O001—O500。本次导出保留原代码ID，不静默覆盖旧包或丢失映射。
2. 原代码的initial score为null不是“忘记初始化”，它同时有明确的unaware状态。目标模型的initial_state=null才表示尚未冻结S/E/I/R初态。两种null含义不同。
3. 本次调用基础initialize，未执行attach_donor_profiles和timeline政策挂载。因此可核对网络与初始行为字段，但不能宣称它是包含全部画像和政策的旧runner完整快照。
