# V3操作指南：只使用这四份文件

本目录共四个文件；没有其他必需的用户输入附件。已准备材料，未部署或调用模型。

## 1. 四个文件各做什么

| 文件 | 用途 |
|---|---|
| [01_Agent基础信息表.csv](./01_Agent基础信息表.csv) | 谁参与、用LLM还是规则、有哪些可用账户属性 |
| [02_Prompt固定提示词.md](./02_Prompt固定提示词.md) | 305名LLM用户每轮怎样判断并输出行动 |
| [03_新环境设定.md](./03_新环境设定.md) | 网络接触、信息展示、政府回应和规则用户的行为边界 |
| 本指南 | 按什么顺序在SocioVerse2中建立研究 |

## 2. 导入人群

读取CSV，一行对应一人。不得重编ID、重新抽样或从外部人群池补人。

| 字段 | 含义 |
|---|---|
| agent_id | 模拟ID |
| decision_mode | llm或rule，用于分配决策方式 |
| group | inside=关注发布者；outside=不关注 |
| follows_source | true／false；导入时显式转换为布尔值 |
| profile_id | 所借用的账户资料编号；规则用户为空 |
| sex、location | 采集时账户显示的性别与所在地，不推断其他属性 |
| following_count、followers_count、statuses_count | 关注数、粉丝数、累计发博数；不直接换算信任或活跃度 |
| profile_status | 资料来源或待核查提示 |
| source_rows | 原Excel工作表和行号，供追溯，不进入普通用户提示词 |

空值表示未知或未分配，不是0。规则用户没有账户资料和人格prompt。LLM用户305份资料各使用一次。

| 原分组 | LLM | 规则 | 合计 |
|---|---:|---:|---:|
| inside | 43 | 39 | 82 |
| outside | 262 | 238 | 500 |
| 合计 | 305 | 277 | 582 |

305／277是用户提出的混合结构；43／262的LLM分配及具体ID对应是按比例形成的实验草案，不是观察到的真实关注或决策类型。此次简化文件沿用已有分配，不重新洗牌。两类用户都在两组内，避免把模型类型与圈内外混为一谈。

## 3. 构建自然语言用户

对llm行，将非空账户属性写成简短的个人资料。例如：“你是用户Axxxx。本实验设定你关注发布者A。账户显示所在地为北京，关注数量为……”。不从性别或地点编造性格，不生成未知年龄、职业、信任经历。

将个人资料填入固定提示词。当前观察由环境提供，本人经历由运行日志提供。第一次没有经历就写“暂无”；不要填入此人在真实事件中的后来评论。

表中的rule行跳过上述过程，按环境文档中的选定概率规则决策。不要因为缺prompt而为规则用户调用LLM。

## 4. 接到SocioVerse2

要求构建agent在研究层完成下面的连接，不修改旧空间概率版本：

1. 人群模块读取CSV，建立固定用户及decision_mode。
2. 环境模块按新环境文档产生各人的实际观察。
3. 决策模块根据decision_mode分流：LLM拼接prompt；规则执行概率合同。
4. 两类结果统一提交到同一环境，转发能跨类型传播；LLM评论下一轮可见。
5. 保存每人的观察、输出、状态和记忆；失败单列，重试不能重复发帖。

对应官方研究接口为PopulationProvider、EnvironmentProvider、DecisionModel和MetricCollector。本包不是平台原生配置，构建agent需检查部署版本并映射字段；上传MD不等于实现provider。[官方架构](https://socioverse.fudan-disc.com/docs/concepts/architecture/)

## 5. 先检查，再运行

先让构建agent显示一名LLM用户的完整输入、一名规则用户的参数与执行记录格式，核对：

- 总人数582；LLM305；规则277；ID唯一；资料编号在LLM组无重复。
- 没有把本事件后来的真实评论或“赞同”标签写入初始人设。
- 没有真实账户资料的规则用户不被标成“真实沉默用户”。
- 两类用户共享环境，且能相互转发传播。
- 同轮新行动不提前进入本轮观察；模型失败不记成不相信。

正式运行还需填写：初始信念、网络边、活跃与阅读设置、时间长度、政府回应全文及排程、规则概率条件和多接触合同、记忆长度、模型和预算。一次性列出缺项，不用默认值填成已确认。当前先完成配置与固定回答测试，不自动调用付费模型。

## 6. 数据来源和限制

来源是用户提供的32.weibotest-fupin2_new(1).xls。账户按ID去重，共305份，来自250条评论和72条转发。基础表仅保留账户属性和来源行号，未导出昵称、主页和真实账户ID；行号仍可关联原表，因此是假名化资料，不是完全匿名资料。仅按研究授权使用，不自动公开或提交到代码仓库。

一名账户的发博数存在16778／16779差异，该字段留空；六名不同账户的属性组合完全相同、需复核，这六份属性暂留空，保留资料编号。资料采集时点未证实早于事件，因此当前适合探索性模型准备，不直接宣称完成真实行为预测。

现有582个ID和分组来自此前合成人群设定；305份真实账户资料为LLM用户提供属性，不代表模拟ID等同于对应真人。其余277人仍是合成规则用户。

与上一版相比，本次只压缩交付形式，没有新增实验条件，也没有运行模拟。此前多文件整合包保留作历史资料；本次构建只读取本目录四份文件，不再混用旧分配方案。
