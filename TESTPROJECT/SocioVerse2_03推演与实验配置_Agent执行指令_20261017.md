# SocioVerse2 推演与实验配置指令

版本：2026-10-17。本文用于方案与接口设计；只有环境、人群和运行范围已确定后才执行正式模拟。无需重新读取旧源码或原稿，不指定本地目录。

## 1. 研究与分工

研究比较政府辟谣时机 T_G、目标 In-out、接受概率 GT 在不同圈内外相信差异 PBd 下的结果。普通用户为 82 名圈内、500 名圈外，身份固定。环境提供有效接触；DecisionModel 执行概率抽样；环境提交动作；MetricCollector 读取结果。不要嵌套旧项目主循环，不使用 LLM 自由决策替代概率。

## 2. 规则合同

| 输入条件 | 执行 | 结果与记录 |
|---|---|---|
| 无有效接触 | 不抽 PB、RC、GT、RF | 保持状态；可记录 no_contact |
| 适用状态下的谣言接触 | 取 u1∈[0,1)，若 u1<PB 则相信 | 失败对应 1−PB；失败后的具体离散状态按已冻结状态转换合同，不能把所有失败都自动改成 R |
| 上一步相信 | 再取独立 u2，若 u2<RC 则传播 | 相信不传播为 E；相信且传播为 I；未相信时不执行 RC 抽样 |
| 有效政府纠正接触 | 取 u3，若 u3<GT 则接受 | 不接受保持原信念；接受转为拒绝谣言并记录转换时点 |
| 上一步接受纠正 | 再取独立 u4，若 u4<RF 则传播纠正 | RF=.6；纠正传播资格与拒绝状态分别保存 |
| 普通用户传播的纠正 | 使用已确定的同伴纠正规则 | 当前接受规则未确定，不自动套 GT |

随机值范围和比较符号是拟定的工程合同，保证 p=0 永不成功、p=1 必成功。原稿没有提供逐次随机序列，不宣称与旧运行逐步数值相同。

同轮多个接触、重复接触、R 是否可重新相信、LC 到期以及初始状态必须先在规则表明确。不得由框架默认同步更新或调用次序代替科学规则决定。

全因子共有 3×9×3×5=405 组条件，但不是本次默认运行量。先选择单事件、一组基准和一个比较条件；正式种子、重复次数和比较条件仍需确定。不要自动生成 81,000 次运行或以测试种子数量充当正式重复数。

草案按原稿表格概率值表达，RC 精确比例与舍入差别保留在版本说明中。无干预条件可以作为候选对照，但不能未经说明自动加入研究设计。

## 4. 时间、随机性与分支

初始化 step 0 与首次更新分开；明确 400 次更新和最终观测的对应关系。T_G 必须按同一映射触发，不因从 0 计数而错一轮。政府启用只改变环境状态，实际曝光仍由接触规则决定。

维护独立的画像、运动和行为随机流；记录 seed、算法和可恢复状态。恢复不能只保存最终状态。对已经发生的前史不重新抽样，分支名称不参与种子计算。

同一政策比较重复内固定人群和所有前干预条件。分支点不晚于最早发生政策差异的时点。不同 PBd、人口或接触规则属于场景／模型版本变化，不冒充仅改变政策的分支。若无法验证确定性回放，使用独立完整运行并说明，不能宣称已实现配对前史。

| 恢复快照 | 环境、用户、信息生命周期、干预进度、待处理接触、全部相关随机状态 |

不要输出虚构的自然语言心理理由；规则编号、概率、随机值和接触事实足以解释动作。失败运行保留失败状态，不将半轮提交或预算中止标作完成。

## 6. 验证顺序

1. 用预设随机值检查 PB→RC、GT→RF 的所有分支，包括 p=0、p=1 和阈值相等。
2. 无接触不抽样；条件不成立不执行后续抽样；每条接触不重复提交。
3. 普通用户始终 582 人，身份固定，状态计数守恒；特殊角色不计入普通用户。
4. T_G 前无政府直接接触；T_G 后不自动全员曝光。
5. 相同输入和种子重跑一致，修改运行名称不改变结果；中断恢复与完整运行一致。
6. 若使用分支，验证前史一致与实际干预差异；未通过不标支持回放。
7. 用人工构造的转换记录验证 TBU；不拿论文结论方向作软件验收标准。

小型固定测试只是工程检查，不是正式实验结果。未执行标 NOT_RUN，不以设计描述冒充通过。

## 7. 指标边界

原稿 TBU=mean(T_i−T_G)，仅计入 T_i>T_G 的完成相信→不相信者。未完成者排除，无完成者返回缺失并报告人数。保留真实时点，不把同轮转换人为挪后。

不复用新版固定干预前相信者集合或 30 轮窗口，不新增匹配／统一随访。新增转变比例的分母未定，暂不计算“成功率”。若重复转换可能发生，须定义用于 T_i 的事件；在规则允许与否未明确时不自行选取。
