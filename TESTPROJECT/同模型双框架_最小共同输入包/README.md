# 同模型双框架：最小共同输入包

## 这次保留什么

目标是让现有Python承载方式与SocioVerse2运行同一个概率模型。这里固定的是共同输入，不是证明数据未经加工。包内所有文件引用均为相对路径；复制或上传整个文件夹后仍可使用。

| 文件 | 内容 | 类型／是否已确定 |
|---|---|---|
| [事件输入](./inputs/event_input.json) | event_052的源帖、实验纠正及证据状态 | 从现有事件记录提取；文本保持不变，不是原始采集文件 |
| [用户身份表](./inputs/population_identity.jsonl) | 同一批582个ID，82圈内、500圈外 | 复用已生成的名册身份；不是582名实测用户；initial_state仍为null |
| [共同模型参数](./inputs/model_parameters.json) | PB/RC三组表、RF、人数、400 ticks、原稿环境参数与干预候选 | 研究设定；候选集合不等于已选择正式运行条件 |
| [比较合同](./inputs/comparison_contract.json) | 两边输入引用、规则合同、初始状态、随机过程与运行条件 | 所有未定项显式为null；runtime_ready=false |
| [来源记录](./PROVENANCE.json) | 来源文件摘要、保留／删除字段、加工性质 | 可以追溯本次整理，不依赖原作者机器 |
| [完整性清单](./MANIFEST.json) | 包内文件SHA256与数量检查 | 两个框架先验证同一版本；清单本身不哈希自身 |

**当前是共同输入草案，不是已具备完整初始化的可运行实验包。** 已有事件、固定身份和参数已经实际放入；尚未确定的空间、状态和时序规则不能凭空补齐。

## 不需要保留什么

本次最小包不包含305份账号画像、历史评论、行为统计、旧版LLM与信息流配置、405组条件枚举、演示HTML或模拟结果。

原因：这些内容不参与当前原稿概率规则，或属于另一个模型／加工结果／展示。没有画像并不妨碍582名规则用户的生成。若以后确认粉丝数等要影响行为或接触，就必须升级共同模型合同并在两个框架中同时加入；不能只在一个框架加载。

这里的“最小”针对已讨论的概率基准。原始Excel不作为前置条件，数据溯源限制仍在来源记录中保留。

## 读取顺序

1. 将本文件夹作为包根目录，读取 `./MANIFEST.json`，检查每个文件的SHA256。不要把运行输出写回这份输入包。
2. 读取 `./inputs/event_input.json`。它不再引用画像或行为汇总文件，不需要追查原工程目录。纠正文本是实验脚本，不能当作真实官方证据。
3. 读取 `./inputs/population_identity.jsonl`。直接复用相同ID与group，两边都不重新抽样或重新分组。特殊角色SOURCE和GOVERNMENT定义在模型参数中，不算入582人。
4. 读取 `./inputs/model_parameters.json`，按双方共同选定的PBd查表。不得由画像、LLM、第五轮相信比例或框架默认配置重新估计PB、RC。
5. 读取 `./inputs/comparison_contract.json`。根目录以该文件的path_base字段为准，不是以JSON所在子目录为准。落实所有运行相关null，再生成一次完整初始快照，两个框架加载同一快照。
6. 冻结完善后的合同、快照和哈希。先做逐步等价验证，再比较性能、恢复和分支管理。仅设置相同seed不能替代初始状态和随机值分配的核验。

## 实施前确实仍需确定的内容

- 选定首次PBd、T_G、In-out、GT及正式重复设计。
- 固定普通用户、谣言源、政府的初始状态与位置／网络。
- 确定接触方式与完整接触、运动、边界、圈层、生命周期和轮内更新规则。
- 确定重复接触、状态反转、同伴纠正接受等行为边界。
- 确定概率精度和随机数分配合同。

这些是同一个模型的定义缺口，不是原始Excel缺失。先集中完成双方共同规则，不能用一方框架默认值代填。

新增转变比例的分母可以暂不确定；两边先不计算它。原稿TBU无完成者记缺失，不以零代替。

## 如何避免“换框架又换模型”

A应为现有Python运行组织接入共同概率核心的版本；B为SocioVerse2接入同一核心的版本。不能A继续用LLM与信息流、B改为概率与空间，却把差异都归因于框架。

双方共同输入不变；框架专属配置由各自适配器生成，不放进共同模型参数覆盖研究含义。每轮比较接触、抽样、动作、状态和指标。只有这些等价后，才比较时间、内存、记录、恢复和分支成本。

## 上传方式

上传整个本文件夹或对应ZIP即可。这份精简包替代此前混合交接包的数据入口，不需要同时上传历史归档。路径采用包内相对路径，不需要对方访问原作者的磁盘。

JSON/JSONL和数据数量已经检查；没有实际执行两框架、没有生成正式初始世界、没有取得框架等价结果。
