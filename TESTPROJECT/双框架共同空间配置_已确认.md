# 双框架共同空间配置

版本：spatial-baseline-v1  
状态：研究者已确认，用于两个框架承载同一模型的第一阶段比较。  
本文件自包含，不使用本地绝对路径。

## 1. 适用范围

现有 Python 承载方式与 SocioVerse2 均采用下列空间、初始化和移动规则，不允许各自使用框架默认值覆盖。

这是为双框架比较确定的共同实施约定，不是从原稿恢复出的全部参数，也不是经过经验校准的真实平台空间。第一阶段固定圈层大小，验证该版本的框架执行一致性；不称为完整原稿复现。

## 2. 世界、用户与谣言源

| 配置项 | 已确认设置 |
|---|---|
| 世界 | 二维正方形，宽100、高100，抽象距离单位 |
| 坐标范围 | x、y均为[-50,50] |
| 谣言源 | 固定在(0,0)，不移动；持续作为有效谣言发送者 |
| 圈层 | 圆心(0,0)，半径20 |
| 圈层变化 | 本版本固定半径，不随相信人数扩大或缩小 |
| 普通用户数量 | 圈内82人、圈外500人，共582人；源与政府另计 |
| 圈内用户初始位置 | 在半径20的圆内按面积均匀分布抽样 |
| 圈外用户初始位置 | 在正方形内、圆外区域均匀抽样 |
| 群体身份 | 初始化后固定；圈外用户进入圆内后仍是圈外用户 |

### 圈内位置抽样

独立抽取 `u,v ~ Uniform(0,1)`，计算：

```text
theta = 2*pi*u
r = 20*sqrt(v)
x = r*cos(theta)
y = r*sin(theta)
```

使用平方根确保按面积均匀，不得将半径直接均匀抽样。

### 圈外位置抽样

独立抽取 `x,y ~ Uniform(-50,50)`；若 `x*x+y*y <= 400`，重抽该坐标对，直到落在圆外。此为正方形减去圆的区域上的均匀拒绝采样。

## 3. 用户运动与边界

| 配置项 | 已确认设置 |
|---|---|
| 方向 | 每tick、每名用户独立抽取theta~Uniform(0,2*pi) |
| 方向记忆 | 不保留上一tick方向 |
| 步长 | 每tick固定2个距离单位，对应本版本对UA=2的实施映射 |
| 轨迹 | 本tick按抽取方向走直线段 |
| 边界碰撞 | 到达允许区域边界时反射，继续走完剩余步长；不截断、不环绕、不重新随机抽方向 |
| 圈内用户 | 仅在圆内活动，在圆边界反射 |
| 圈外用户 | 可自由穿越圈边界，只在正方形外边界反射 |

反射采用镜面反射：若单位方向为d、碰撞面单位法向量为n，则反射方向为 `d' = d - 2*(d·n)*n`。反射后继续消耗本tick剩余路程。

角点碰撞、浮点误差容差和恰落边界的数值处理属于待统一的底层实现约定。两边必须使用相同的几何实现或相同的数值约定，不能各自默选不同算法；本文件没有给出经验证的容差数值。

## 4. 有效接触

| 配置项 | 已确认设置 |
|---|---|
| 检测时点 | 本tick移动结束后 |
| 接触阈值 | 接收者与有效发送者的欧氏距离小于或等于2 |
| 路径中途相遇 | 本版本不检测，只检查移动后的终点距离 |
| 源接触 | 使用相同阈值2 |
| 用户之间 | 每个有向发送者—接收者对每tick最多一条接触记录 |
| 跨tick重复 | 可以再次生成接触；是否再次更新信念由共同状态转换合同决定 |

接触生成不等于相信或转发。生成有效接触后，才由共同概率模型执行PB→RC或政府接触下的GT→RF。不因检测到距离相近就提前修改信念，也不再增加未经确认的第二层接触概率。

多个发送者同时接触同一用户的处理顺序、普通用户纠正传播的接受规则等，不由本空间配置自动决定。

## 5. 政府初始化、启用与运动

| 配置项 | 已确认设置 |
|---|---|
| 初始化时点 | tick 0生成并保存位置 |
| T_G之前 | 不移动、不产生政府纠正接触 |
| T_G起 | 每tick随机移动，再检测接触；T_G当tick包含在内 |
| 移动方向 | 每tick独立抽取theta~Uniform(0,2*pi) |
| 移动步长 | 每tick固定1个距离单位 |
| 接触 | 移动结束后，距离小于或等于2的用户实际接触政府纠正，再执行GT→RF |

| In-out | 初始位置 | 移动与边界 |
|---|---|---|
| 2：圈内 | 圆内按面积均匀抽样 | 限于圆内，在圆边界反射 |
| 1：随机 | 整个正方形内均匀抽样 | 可穿越圆边界，仅在世界边界反射 |
| 0：圈外 | 正方形内、圆外区域均匀抽样 | 不进入圆，在圆边界和世界外边界反射 |

这里的政策约束是政府活动区域，不是额外的用户身份筛选。例如圈外身份用户进入圆内，仍可能被圈内活动的政府实际接触。不得在距离判定后再偷偷加入“只纠正同类身份用户”的筛选。

## 7. 两个框架如何获得相同起点

1. 固定用户ID与群体身份，依据本配置只生成一次初始用户坐标。
2. 在同一政策条件下，只生成一次政府初始位置，保存源的位置和其他初始状态。
3. 将完整初始快照同时交给两个框架加载。不得让两个框架各自重新抽样，即使使用相同seed也不作为起点一致的证明。
4. 保存本配置、快照、随机数算法与分配规则及其哈希。运行期间方向抽样也要按相同语义事件取得相同随机值。
5. 每tick先比较位置，再比较接触，之后比较概率决策、动作、提交后的状态及指标；第一处分歧需定位，不能只看最终曲线相似。

更换In-out时，政府初始位置与活动范围属于政策差异。跨框架比较同一条件时必须一致；跨政策分支若要复用前史，需明确如何处理政府位置变化，不能直接宣称不同政策具有完全相同的世界初态。

## 8. 相对原稿的改动登记

| 项目 | 原稿／先前材料 | 本次共同基准 |
|---|---|---|
| 世界几何 | 未获得完整可执行定义 | 正方形100×100 |
| 初始分布 | 原稿只说明随机初始化 | 圈内面积均匀、圈外区域均匀 |
| 方向与边界 | 原稿未完整说明 | 独立均匀方向、镜面反射 |
| 距离阈值 | 未获得明确阈值 | 2，含端点 |
| 接触时点 | 未获得完整路径检测规定 | 移动后终点检测，不检测路径中途相遇 |
| 政府区域 | 原稿区分主要圈内、随机、主要圈外 | 具体化为本文件规定的区域及反射约束 |
| 圈层变化 | 原稿描述随相信者变化扩大／缩小 | 第一阶段固定半径20；明确简化 |
| PR=11.7 | 原稿传播范围参数 | 不拿来充当本基准的几何半径 |

上述新增几何数值是已确认的工程基准，不是已验证的经验估计。固定圈层比较通过后，若加入动态圈层，须形成新配置版本并同时更新两个框架。

## 9. 本次没有自动确认的内容

本次确认的是空间配置。普通用户S/E/I/R初态、同tick多接触决策顺序、逆转规则、同伴纠正接受、概率精度、正式种子与重复次数等，仍按共同模型合同另行冻结。

因此本文件可以固定空间起点的生成规则，但不表示已经生成实际坐标、完成全部初始状态、实现两个框架或运行等价验证。LC=250也没有因此被解释成硬失效时点。
